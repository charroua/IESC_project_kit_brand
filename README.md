# IESC Project Brand System

Reusable design system for the Vietnam Temperature-Controlled Logistics market study.

## Source of truth
- `brand-tokens.json` — colors and typography tokens
- `BRAND-GUIDE.md` — visual hierarchy, typography, chart and report rules
- `brand.css` — implementation reference

## Typography
- **Bespoke Serif Medium** — editorial/display titles and insight headlines
- **Aptos** — body text, charts, tables, KPIs, captions and sources

## Core palette
- Deep Navy `#0B2E59`
- Report Teal `#006A83`
- Primary Gold `#DDB534`

Font binaries are intentionally not included.
