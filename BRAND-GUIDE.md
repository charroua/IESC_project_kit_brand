# Vietnam TCL Market Study — Brand Guide

## Typography
- **Titles / editorial headlines:** Bespoke Serif Medium
- **Body / charts / tables / captions:** Aptos
- **Fallbacks:** Georgia for headings; Arial for body text

> Font files are not included. Only use/distribute Bespoke Serif according to its license.

## Core colors
| Token | HEX | Use |
|---|---|---|
| Deep Navy | `#0B2E59` | Main titles, icons, actual-data series |
| Report Teal | `#006A83` | Insight headlines, chart titles |
| Primary Gold | `#DDB534` | Forecast series and analytical highlights |
| Soft Gold | `#F4E8B7` | Highlight backgrounds |
| Pale Blue | `#EAF3F8` | Callout/KPI backgrounds |
| Slate Blue | `#7FA3B8` | Rules, borders, secondary accents |
| Body Charcoal | `#333333` | Main body copy |
| Mid Gray | `#6E7781` | Notes and secondary text |
| Light Gray | `#E7EBEE` | Gridlines and dividers |
| White | `#FFFFFF` | Main background |

## Chart convention
- Actual: `#0B2E59`
- Forecast: `#DDB534`
- Secondary series: `#006A83`
- Gridlines: `#E7EBEE`
- Labels: `#0B2E59`

## Writing / page logic
Use: **fact → calculation → interpretation → investment relevance**.

Typical page:
1. Section/subsection marker
2. Insight-led headline
3. Short context paragraph
4. Hero exhibit(s)
5. Concise analytical interpretation
6. Source and forecast note
